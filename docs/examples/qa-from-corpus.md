## Как прогнать

В UI задайте вопросы по очереди при загруженных четырёх PDF. Через API:

```powershell
curl http://127.0.0.1:8000/api/ask -H "Content-Type: application/json" -d "{\"question\":\"Какая цель выпускной работы Пешкова?\"}"
```

В `chunks` должна быть ссылка на нужный `source` и близкая `page`. Для контрольного отказа спросите, например: «Какой счёт в финале ЧМ-2022?» — источников быть не должно.
